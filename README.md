# Product Sales Analysis

## Project Overview

This project analyzes product sales data using Python libraries such as Pandas, NumPy, and Matplotlib. The objective of the project is to identify sales trends, top-selling products, regional sales performance, and generate business insights from the dataset.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Google Colab

## Dataset Columns Used

* OrderDate
* Product
* Quantity
* TotalPrice
* ShippingCost
* Discount
* RegionManager

## Project Workflow

1. Data Loading
2. Data Cleaning
3. Date Formatting
4. Monthly Sales Analysis
5. Product-wise Sales Analysis
6. Region-wise Sales Analysis
7. Statistical Analysis using NumPy
8. Correlation Analysis
9. Data Visualization

## Key Analysis Performed

* Top 10 Selling Products
* Monthly Sales Trend Analysis
* Sales by Region Manager
* Product-wise Revenue Analysis
* Correlation between Sales, Quantity, Shipping Cost, and Discount
* Statistical Analysis of Sales Data

## Visualizations

* Bar Charts
* Line Charts
* Correlation Analysis
* Sales Trend Graphs

## Business Insights

* Identified top-selling products
* Analyzed monthly sales performance
* Compared regional sales contributions
* Evaluated sales statistics and trends
* Generated insights for business decision-making
